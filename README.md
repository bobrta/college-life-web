# College OS 網站

這是 College OS 的精簡靜態網站版本。此公開儲存庫不包含私人知識庫、課程行程、個人紀錄或 Supabase 金鑰。

## 部署

在 GitHub 的 Settings → Pages 將 Build and deployment source 設為 GitHub Actions，然後到 Actions 執行「Publish College OS」。

## 現況

Email 登入與跨裝置同步尚未啟用；知識檔與個人行程需另行匯入。

## 時間規劃

開啟 `planner.html`，或從首頁「時間規劃・容量計算」進入。

1. 設定每週各日可用時段、每日淨工時與主要工作件數上限。
2. 加入固定課程、交通、補課、週日規劃與保護休息；可從同一瀏覽器的原日曆讀取固定事件。
3. 任務填剩餘估時、期限、完成條件及前置任務；可連結月／季目標。
4. 檢查建議排程與缺口，再保存確認快照。單日例外可降低某天容量。
5. 使用專注／休息計時，校正剩餘估時，核對完成條件後確認完成。

容量依可用區段、固定事件、專注休息節奏、每日上限和緩衝計算。排程使用期限及重要性排序的啟發式方法，並非保證最優解。只安排當下以後的時段，月／季沿用每週設定作容量情境估算。

資料只儲存在瀏覽器；跨裝置需匯入備份。ICS 是單次匯入，不會自動同步。PDF 使用瀏覽器列印。瀏覽器關閉時不保證休息通知。確認快照保留歷史安排，但不是鎖定重排功能。

驗證：`node --test tests/planner.test.mjs`。涵蓋重疊行程、休息、件數、期限、依賴、備份、多時段及單日例外。操作流程另以 DOM 模擬確認；尚未完成實際瀏覽器視覺驗證。

## 模組化維護

時間規劃核心已拆分至 `規劃核心/`，排程顯示位於 `規劃介面/`；設計與擴充規則見 [時間規劃架構](docs/時間規劃架構.md)。

```bash
node --test tests/*.test.mjs
node scripts/build-planner.mjs
```

保存層支援舊資料遷移、20步復原重做與跨分頁衝突偵測。計時期間清除復原歷史以避免重複計時。月季按週折疊，展開時才建立每日卡片。線上版與單檔版共用同一套源碼。

### 50項問題修復

詳見 [修復紀錄](docs/50項問題修復紀錄.md)。核心測試：`node --test tests/*.test.mjs`；操作測試：先 `npm install --prefix tests/ui`，再 `npm test --prefix tests/ui`。操作測試為DOM模擬，非實際瀏覽器驗證。
