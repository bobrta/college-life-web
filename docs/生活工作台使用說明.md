# 生活規劃工作台：可直接使用的版本

下載 `時間規劃_單檔版.html` 後以瀏覽器開啟；不需要登入或連網。線上版與單檔共用程式來源。

## 已提供的功能

- 同頁行程、任務、資源、財務及活動恢復區；導覽只捲動，不切換頁面。
- 日、週、月、季、年範圍，支援上一期、下一期與回到今天。年度沿用每週容量規則，是情境估計，不代表全年已確認。
- 週視圖以並排日卡呈現固定行程與建議工作；排程優先顯示，匯出、容量檢查與計時可收合。
- 「同步兩個日曆」會把兩個本機入口的固定行程合併到主日曆；只新增、不刪除，同 ID 衝突保留主日曆版本，不會同步建議讀書區塊。
- 手動表單、格式化指令及單筆JSON。先预覽，再一次保存；無法解析不會執行。
- 時間區5種檢視，財務、決策及活動區各4種檢視；圖表附數字明細。
- 台幣總帳：期初餘額、實際收支、預定收支、儲備金及依日期範圍保存的預算。
- 財務預測含未完成的過期預定，會提醒核對；「今天已收／付」把同一筆轉為實際，不重複扣款。
- 資源文字盤點，必做、想做、進行中和完成事項。新增決策時建立關聯任務；預設最多3件決策進行中，可設1–4件。
- 決策估計成本用於提醒，不會自動變成實際支出。時間或金額不足會提示，並不代替你作决定。
- 活動、睡眠及主觀疲勞紀錄。睡眠0代表未填；同一天有多筆睡眠時，圖表採最後一筆已填數字。活動分鐘不包含恢復類別。
- ICS選擇建議或確認快照，可包含固定行程；固定重複事件按選定日期展開，包含單次覆寫。Google日曆為檔案匯入，沒有持續同步。
- PDF透過瀏覽器列印另存。預設只印行程與時間分析；選「全部」才含財務和活動。列印結束恢復原收合狀態。
- 生活資料沿用原規劃器的備份、復原與保存失敗保護。主日曆與生活規劃仍是不同儲存紀錄；同步固定行程時才會合併，且不同瀏覽器儲存區不會互通。

## 第一次設定

1. 在「時間與休息」核對可用時段、每日件數及強制休息。固定課程和生活時間要先加入。
2. 財務設定填「開始記帳前」總餘額；不要把現在餘額加上已記錄收入重複計算。
3. 「資源與決策」填現有材料，新增一件必做，按開始推進加入排程。
4. 核對建議，確認排程後使用計時；週日匯出備份並調整下一週。

## 可貼上的指令

```text
/cal 2026-10-15 14:00-15:00 [管理學報告] $150
/fin -150 #餐費 [午餐]
/fin 2026-10-20 -300 #交通 [考試交通] !預定
/task [微積分第一章] 2h -> must
/fit 20m #walk [散步]
```

行程指令的費用是預定支出；刪除行程不會自動刪除費用，紀錄會提醒核對。未來活動請建立行程，不可用活動紀錄冒充完成。

```json
{
  "kind": "cal",
  "date": "2026-10-15",
  "start": "14:00",
  "end": "15:00",
  "title": "管理學報告",
  "cost": "150"
}
```

指令kind包括cal、fin、task、fit；完整日期使用YYYY-MM-DD。Cmd/Ctrl＋K將游標移至輸入欄。
