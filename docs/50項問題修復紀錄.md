# 50項問題修復紀錄

這次以重構版（PR #2原始版本）為基準，重現50項缺陷：30項資料驗證、13項時間與排程、7項操作流程。每項都有獨立回歸案例；並非50項重大故障，其中包含不合法備份資料未被拒絕的邊界問題。

舊版50個案例全部失敗；修正版全部通過。連同原有26個測試，共76個測試通過。操作測試使用DOM模擬，尚未做實際瀏覽器視覺驗證。

## 檢查方式

```bash
node --test tests/*.test.mjs
npm install --prefix tests/ui
npm test --prefix tests/ui
node scripts/build-planner.mjs
```

P01–P43位於 `tests/planner-50.test.mjs`，P44–P50位於 `tests/ui/planner-ui.test.mjs`。可設定 `PLANNER_TEST_ROOT` 指向舊版目錄，比較相同案例的結果。

額外保護：計時中的工作須先結束計時才能修改估時或確認完成；匯入失敗會恢復已保存狀態；估時歸零但尚未確認完成的工作會顯示提醒。

線上頁面與離線單檔由同一來源建置。離線版可直接開啟，資料保存在目前瀏覽器，仍應定期匯出備份；PR尚未合併前，正式線上版本不會更新。
